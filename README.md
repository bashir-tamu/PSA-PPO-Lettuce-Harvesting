# Sim-to-Real Reinforcement Learning for Path-Safe Target Reaching in Robotic Harvesting of Hydroponic Lettuce

**Manuscript and code coming soon.**

This repository is the project page for **Path-Safe Approach Proximal Policy Optimization (PSA-PPO)**, a reinforcement-learning approach to robotic target reaching in constrained harvesting environments. In hydroponic lettuce harvesting, reaching a target is only part of the manipulation problem: the robot must also account for collision avoidance with neighboring crops and cultivation infrastructure during its approach.

The study investigates learning-based, path-aware robot motion and its transfer from simulation to a physical harvesting system. The full research details, implementation, and supporting materials will be added as they become available for public release.
